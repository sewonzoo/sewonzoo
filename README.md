## 🧑‍💻 About Me

기획·프론트엔드·PM을 거쳐 지금은 백엔드에 집중하고 있습니다.
화면보다 **데이터 구조와 API 같은 서비스의 뼈대를 설계하는 일**에 더 끌려 방향을 잡았고,
설계에서 끝나지 않고 실제로 배포까지 완주하는 백엔드를 만드는 것을 목표로 하고 있습니다.

현재 홍익대학교에서 졸업을 앞두고 있으며, 캠퍼스 안내 앱의 백엔드 전체를 맡아 진행 중입니다.
